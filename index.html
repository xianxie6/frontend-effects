网站的高级感很多来自滚动、过渡和质感

用的时候

  1. 一个页面选 1 个风格词，再加 2–3 个鼠标或点缀词就够了。全用上会很吵。
  2. 每个动效都要有用处：给反馈（涟漪）、引导视线（磁吸、流光）、做出层次（倾斜、视差）。
  3. 时长参考：微交互 150–300ms，卡片和面板 300–600ms，背景氛围 8–20s。
  4. 只给 transform 和 opacity 做动画；blur 和 backdrop-filter 少用，它们最耗性能。
  5. 用 prefers-reduced-motion 给减弱动效的用户降级；鼠标类效果在触屏上关掉或改成点击。
  6. 更完整的提示词：做一个【效果名 + 英文名】用在【哪个元素】上，参数【角度 / 时长 / 半径 / 缓动】，触发方式【悬停 / 点击 / 滚动】，手机上【关闭 / 改为点击】。
